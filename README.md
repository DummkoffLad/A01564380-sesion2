# Python Purchase Calculator

An introductory Python exercise using console input, numeric types, and a conditional discount.

`ejercicio1.py` calculates a purchase total from an item price and quantity, plus a second item's price and weight. Entering `Si` for the points-card question applies a 10% discount.

## Run

```bash
python ejercicio1.py
```

Python 3 is required; there are no third-party dependencies. The script expects numeric input and does not yet handle invalid entries.

The original Codespaces and Python class notes are preserved in [docs/course-notes.md](docs/course-notes.md).
